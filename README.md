# 茶见商机

面向中国茶叶行业经营者的中文 B2B 获客网站静态首版。页面包括业务定位、目标客户类型、合作沟通步骤和业务咨询表单，支持移动端布局及浏览器端表单校验。

## 本地预览

直接在浏览器中打开 `index.html` 即可预览，无需安装依赖或启动构建流程。

## 表单与隐私

当前表单仅在浏览器内进行演示校验，不会发送、存储或转交填写内容，也未接入自动化获客或后端服务。手机号为必填项，页面会提示信息仅用于回复本次咨询；在启用真实提交前，需先配置后端接收端点、明确隐私告知与数据保存规则，并按适用法律法规处理用户主动提交的信息。

页面不会抓取、购买或未经许可收集个人信息，也不包含虚构客户案例、业绩或资质声明。
